# How to run tests
To run tests you need to have an mqtt broker running on your computer. The attached mosquitto.conf file will suffice, or you can make your own.

# cil-gw

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.2.21. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
